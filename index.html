Installইনস্টল

Up and running in two minutes.দুই মিনিটে চালু।

  1. Unzip the downloadডাউনলোড unzip করুন

    JM-Vocal-Channel-macOS.zip contains the AU, the VST3 and the Standalone app.

    JM-Vocal-Channel-macOS.zip-এ AU, VST3 ও Standalone app আছে।

  2. Copy the plug-insplug-in কপি করুন

    JM Vocal Channel.component goes to ~/Library/Audio/Plug-Ins/Components/ (Logic Pro, GarageBand and other AU hosts). JM Vocal Channel.vst3 goes to ~/Library/Audio/Plug-Ins/VST3/.

    JM Vocal Channel.component যাবে ~/Library/Audio/Plug-Ins/Components/-এ (Logic Pro, GarageBand ও অন্য AU host)। JM Vocal Channel.vst3 যাবে ~/Library/Audio/Plug-Ins/VST3/-এ।

  3. Allow it once in TerminalTerminal-এ একবার অনুমতি দিন

    The build is not notarized by Apple, so macOS may say the plug-in is damaged or from an unidentified developer. Paste this once and press Return:

    Build-টি Apple-এর notarize করা নয়, তাই macOS বলতে পারে plug-in নষ্ট বা অচেনা developer-এর। এটা একবার paste করে Return চাপুন:

    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"JM Vocal Channel.component" ~/Library/Audio/Plug-Ins/VST3/"JM Vocal Channel.vst3"

    For the Standalone app, right-click → Open the first time.

    Standalone app প্রথমবার right-click → Open দিয়ে খুলুন।

  4. Rescan in your DAWDAW-তে আবার scan করুন

    Not listed? Quit the DAW, run killall -9 AudioComponentRegistrar in Terminal, then rescan.

    তালিকায় না এলে DAW বন্ধ করে Terminal-এ killall -9 AudioComponentRegistrar চালান, তারপর scan করুন।

  1. Extract the downloadডাউনলোড extract করুন

    Right-click JM-Vocal-Channel-Windows-VST3.zip and choose Extract All.

    JM-Vocal-Channel-Windows-VST3.zip-এ right-click করে Extract All বেছে নিন।

    Inside is JM Vocal Channel.vst3. It is a folder and must stay whole: copy all of it, not a single file from inside.

    ভেতরে JM Vocal Channel.vst3 আছে। এটা একটা folder আর পুরোটা অক্ষত থাকতে হবে: ভেতরের একটা ফাইল নয়, পুরোটা কপি করুন।

  3. Copy it to the VST3 folderVST3 folder-এ কপি করুন

    Paste it into the folder below. Windows asks for administrator permission: choose Continue.

    নিচের folder-এ paste করুন। Windows administrator অনুমতি চাইবে: Continue চাপুন।

SmartScreen or antivirus warning? The file is not code-signed yet. If you trust it, choose More info → Run anyway or allow the file. If it does not load on a computer that never had other plug-ins, install the Microsoft Visual C++ Redistributable (x64) from Microsoft, then rescan.

Questionsপ্রশ্ন

Good to know.জেনে রাখুন।

What happens without a valid key?বৈধ কী না থাকলে কী হয়?

The plug-in does not change the sound at all: your audio passes through unprocessed. The button at the bottom right tells you what is wrong (no key, key ended, key not valid, or check the computer date).

Plug-in সাউন্ড একটুও বদলায় না: আপনার অডিও অপরিবর্তিত পাস হয়ে যায়। নিচে ডানদিকের বোতাম বলে দেয় কী সমস্যা (কী নেই, কী শেষ, কী অবৈধ, বা কম্পিউটারের তারিখ দেখুন)।

Does it work offline?অফলাইনে চলে?

Yes. The key is checked inside the plug-in, so no internet connection is needed. The plug-in notices if the computer clock is turned back.

হ্যাঁ। কী plug-in-এর ভেতরেই যাচাই হয়, তাই ইন্টারনেট লাগে না। কম্পিউটারের ঘড়ি পেছনে ঘোরালে plug-in তা ধরে ফেলে।

Which DAWs and formats?কোন DAW ও format?

macOS: Audio Unit, VST3 and Standalone, on Apple Silicon. Windows: 64-bit VST3. Mono and stereo tracks both work, and no delay compensation is needed (0 samples of latency).

macOS: Audio Unit, VST3 ও Standalone, Apple Silicon-এ। Windows: 64-bit VST3। Mono ও stereo দুই রকম track-ই চলে, delay compensation লাগে না (০ sample latency)।

Is it code-signed?এটা কি code-signed?

Not yet. That is why macOS asks for the one-time Terminal step and Windows may show a SmartScreen warning. The SHA-256 values in the download section let you check that your download is the file we published.

এখনও না। তাই macOS-এ একবার Terminal ধাপ লাগে আর Windows SmartScreen সতর্কতা দিতে পারে। ডাউনলোড অংশের SHA-256 মান দিয়ে মিলিয়ে দেখতে পারেন আপনার ডাউনলোড আমাদের প্রকাশ করা ফাইলই কি না।

Does it match a hardware unit?এটা কি কোনো hardware-এর সঙ্গে মেলে?

No such claim is made. It is analog-modelled, with starting points measured on real vocals. Your ears decide the final setting.

এমন কোনো দাবি করা হয় না। এটা analog-modelled, শুরুর মানগুলো আসল ভোকাল মেপে নেওয়া। শেষ সিদ্ধান্ত আপনার কানের।
