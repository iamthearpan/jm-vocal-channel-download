Installইনস্টল

macOS

Install on macOSmacOS-এ ইনস্টল

  1. Download and unzip JM-Vocal-Channel-macOS.zip. You get the AU, the VST3 and the Standalone app.
  2. Copy JM Vocal Channel.component to ~/Library/Audio/Plug-Ins/Components/ (for Logic Pro, GarageBand and other AU hosts).
  3. Copy JM Vocal Channel.vst3 to ~/Library/Audio/Plug-Ins/VST3/ (for DAWs that use VST3).
  4. The build is not notarized by Apple, so macOS may say the plug-in is damaged or from an unidentified developer. Run this once in Terminal and press Return: 
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"JM Vocal Channel.component" ~/Library/Audio/Plug-Ins/VST3/"JM Vocal Channel.vst3"
    For the Standalone app, open it with a right-click → Open the first time.
  5. Open your DAW and rescan plug-ins. If it is not listed, quit the DAW, run killall -9 AudioComponentRegistrar in Terminal, and rescan.
  1. JM-Vocal-Channel-macOS.zip ডাউনলোড করে unzip করুন। AU, VST3 ও Standalone app পাবেন।
  2. JM Vocal Channel.component কপি করুন ~/Library/Audio/Plug-Ins/Components/-এ (Logic Pro, GarageBand ও অন্য AU host-এর জন্য)।
  3. JM Vocal Channel.vst3 কপি করুন ~/Library/Audio/Plug-Ins/VST3/-এ (যে DAW VST3 ব্যবহার করে তার জন্য)।
  4. Build-টি Apple-এর notarize করা নয়, তাই macOS বলতে পারে plug-in নষ্ট বা অচেনা developer-এর। Terminal-এ একবার এটা চালিয়ে Return চাপুন: 
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"JM Vocal Channel.component" ~/Library/Audio/Plug-Ins/VST3/"JM Vocal Channel.vst3"

  5. DAW খুলে plug-in আবার scan করুন। তালিকায় না এলে DAW বন্ধ করে Terminal-এ killall -9 AudioComponentRegistrar চালান, তারপর scan করুন।
Windows

Install on WindowsWindows-এ ইনস্টল

  1. Download JM-Vocal-Channel-Windows-VST3.zip, right-click it and choose Extract All.
  2. Open the extracted folder. Inside is a folder named JM Vocal Channel.vst3 — it is a folder, and it must stay whole.
  3. Copy that whole folder to C:\Program Files\Common Files\VST3\. Windows asks for administrator permission: choose Continue.
  4. Open your DAW and rescan plug-ins (many DAWs do it at start-up). Insert JM Vocal Channel on a vocal track.
  5. Windows SmartScreen or an antivirus program may warn, because the file is not code-signed. If you trust it, choose More info → Run anyway, or allow the file.
  6. If it does not load on a computer that never had other plug-ins, install the Microsoft Visual C++ Redistributable (x64) from Microsoft, then rescan.
  1. JM-Vocal-Channel-Windows-VST3.zip ডাউনলোড করে right-click করুন, Extract All বেছে নিন।
  2. বের হওয়া folder খুলুন। ভেতরে JM Vocal Channel.vst3 নামে একটি folder আছে — এটা folder-ই, আর পুরোটা অক্ষত থাকতে হবে।
  3. ওই পুরো folder কপি করুন C:\Program Files\Common Files\VST3\-এ। Windows administrator অনুমতি চাইবে: Continue চাপুন।
  4. DAW খুলে plug-in আবার scan করুন (অনেক DAW চালু হওয়ার সময় নিজেই করে)। ভোকাল track-এ JM Vocal Channel insert করুন।
  5. ফাইল code-signed নয় বলে Windows SmartScreen বা antivirus সতর্কতা দিতে পারে। ভরসা থাকলে More info → Run anyway দিন বা ফাইলটি allow করুন।
  6. যে কম্পিউটারে আগে কোনো plug-in ছিল না, সেখানে load না হলে Microsoft-এর Visual C++ Redistributable (x64) install করুন, তারপর scan করুন।

What happens without a valid key?বৈধ কী না থাকলে কী হয়?

The plug-in does not change the sound at all: your audio passes through unprocessed. The button at the bottom right tells you what is wrong (no key, key ended, key not valid, or check the computer date).

Plug-in সাউন্ড একটুও বদলায় না: আপনার অডিও অপরিবর্তিত পাস হয়ে যায়। নিচে ডানদিকের বোতাম বলে দেয় কী সমস্যা (কী নেই, কী শেষ, কী অবৈধ, বা কম্পিউটারের তারিখ দেখুন)।

Does it work offline?অফলাইনে চলে?

Yes. The key is checked inside the plug-in; no internet connection is needed. The plug-in notices if the computer clock is turned back.

হ্যাঁ। কী plug-in-এর ভেতরেই যাচাই হয়; ইন্টারনেট লাগে না। কম্পিউটারের ঘড়ি পেছনে ঘোরালে plug-in তা ধরে ফেলে।
